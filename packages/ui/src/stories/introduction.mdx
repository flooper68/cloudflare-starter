# Component library

React components for apps built from this starter, in Linear's visual language: dark-first,
dense, quiet, keyboard-first. They are themed entirely by CSS variables, so a project
re-skins the whole library by editing its brand (`packages/ui/src/brand/`), described in
`docs/how-to-define-branding.md`.

- **Foundations**: brand, colours, type, elevation.
- **Actions, Forms**: buttons, inputs, selects (incl. async and multi), date pickers.
- **Overlays, Feedback**: dialogs, sheets, menus, command palette, toasts, banners.
- **Data display, Navigation**: badges, avatars, data tables, lists, tabs, pagination.
- **Patterns**: app shell, issue list, kanban board, filter bar, settings page.

Use the toolbar to switch between the dark and light theme. Rules for writing components
are in `packages/ui/CONVENTIONS.md`.
