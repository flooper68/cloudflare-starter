# Agent skills and subagents

The catalogue of every skill and subagent this repository ships in `.claude/`: what each does, when an agent uses it, and what it must ask the owner instead of doing itself. Use when you look for a skill before starting a setup task, decide whether a change needs the reviewer, or add, rename or remove a skill or subagent.

Claude Code loads them from `.claude/` on its own: a skill when a task matches its `description`, a subagent when an agent hands it work. Other coding agents read the same files as plain Markdown. A skill is a short procedure that links its guide; the guide stays the one home of the facts ([documentation.md](documentation.md#rules)).

## Adding, renaming or removing one

1. Write the skill as `.claude/skills/<name>/SKILL.md` (front matter `name: <name>` and a `description` that says what it does and when to use it), or the subagent as `.claude/agents/<name>.md` (front matter `name`, `description`, `tools`). Keep it short and link the guide or process that holds the facts.
2. Add, change or remove its row here, the link to the file in the first cell.
3. Run `bun run test:unit`: `test/architecture/agent-catalogue.test.ts` fails when a shipped skill or subagent has no row, a row names one that does not exist, or a front matter `name` does not match its file.

How the skills and the reviewer fit into a change from request to deploy: [agentic-workflow.md](agentic-workflow.md).
