# Docs

Index of the repository's documentation, in the order of the docs site: start, what each feature does, how to do things, how it fits together, reference, and how agents work here. Each entry says when to read it. Where each kind of doc belongs is in [processes/documentation.md](processes/documentation.md).

## Start a project

Paste this into a coding agent in an empty folder, with your app's name for `<name>`; it runs the `start-project` skill ([how-to-start-a-project.md](guides/how-to-start-a-project.md) has what it does and the steps by hand):

```text
Create a new agent-native app called <name> from the template https://github.com/flooper68/cloudflare-starter. Read its AGENTS.md first, then follow its start-project skill (.claude/skills/start-project/SKILL.md). Ask me for each decision it needs, and before every change to my GitHub or Cloudflare account.
```

## Start in three steps

:::steps
1. **Run it locally.** Clone, install, run: everything runs on your machine, with nothing to sign up for. [Run it locally](start/run-locally.md), then [deploy](start/deploy.md); [what it costs](start/what-it-costs.md).
   ::shot{id="dashboard" alt="The dashboard of a freshly started app, with the getting-started checklist"}
2. **Choose your modes.** Workspaces, sign-up and billing, per environment, by asking your coding agent. [Workspaces](features/workspaces.md), [billing](features/billing.md).
3. **Deploy and connect an agent.** Deploy to Cloudflare, then add `https://<your-app>/mcp` as a connector in Claude. [Let agents use your app](features/agents.md).
   ::shot{id="consent" alt="The consent page an agent shows before it gets access"}

:::
